# 雲朵冒險美術與戰鬥更新

## 已實作

- 三張 GPT 生圖圖集：大耳狗六個姿態、六個世界背景、六位原創魔王。
- 世界選單、世界內頁及答題戰場使用相應的主題場景。
- 角色漂浮、星光攻擊、受到攻擊、傷害數字、勝利與失敗動態；支援減少動態偏好。
- 移除「商與餘數」模式切換，統一使用直式逐步作答及遊戲內數字鍵盤。
- 魔王有 8 點生命，完成一道題扣 1 點。每個直式步驟答錯，玩家扣 1 點；三種難度分別有 5／4／3 點生命。
- 玩家生命歸零即失敗，不解鎖關卡、不發通關獎勵，可重新挑戰。既有答題獎勵保留。
- 生命值由共用遊戲引擎處理，雲端 API 使用同一引擎；操作編號防止重複扣血，舊存檔相容。
- 全螢幕按鈕及不支援時的 Safari「加入主畫面」說明。
- 每日任務獨立一頁，收藏每頁 8 件、紀錄每頁 5 筆、直式示範每頁一輪。
- 以 iPad Pro 12.9 吋橫直向尺寸調整版面；不以隱藏整頁溢出來遮掉必要控制項。

## 部署狀態與順序

目前是待發布版本。執行 Sites source workflow 時，工作環境無法連線至 git.chatgpt-team.site:443，因此未成功推送、保存新版本或更新正式網站。

1. 在可使用 Sites 發布工具及部署網路的環境，沿用 `.openai/hosting.json` 的 project_id，完成原始碼同步與 Sites Worker 建置／發布。
2. 在 iPad Safari 檢查 1366×1024 與 1024×1366（也包含瀏覽器工具列壓縮後高度），測試全螢幕、最後一輪直式、提示、註冊及魔王勝敗。
3. 確認雲端支援 `step-answer` 操作後，再合併至 GitHub main，讓 `/docs` 發布新版前端。

不要在後端仍是舊版本時先合併新版前端，否則登入帳號的逐步錯誤提交會被舊 API 拒絕。
