## 2026-10-18 平板相容更新

- 自動辨識 iPad／觸控平板，頂端可切換電腦版與平板版；選擇保存在裝置。
- iOS 改用頁面內滿版，避免原生全螢幕的退出叉叉與下滑退出手勢。Safari 工具列與作業系統手勢仍由系統控制；可加入主畫面以獨立視窗啟動。
- 遊戲圖片禁止原生拖圖；平板版抑制長按圖片選單，輸入欄仍可正常編輯。
- 平板動畫透過透明 2D 畫布呈現 WebGL 動畫結果；採一致的預乘透明度，移除角色 SVG 陰影合成，透明角色圖層不攔截擺飾操作。
- 移除擺飾繼承的按鈕按下位移與過渡。放手保存相同座標，不重建房間或重新隨機切換動作。
- 擺飾角落縮放固定對角、保持比例；身上配件維持身體定位，使用同樣的方向性縮放。可縮到原尺寸 5%，縮過對角不會反向放大。
- 身上配件由工具列「調整」按鈕選取，避免透明配件區域擋住後方擺飾；平板四角控制點加大。
- 六世界加入不同配器與節奏：笛音、豎琴三拍圓舞曲、鋼鼓切分節奏、稀疏鐘琴、慢弦樂、號角；各世界魔王曲也使用對應配器。

驗證：24 個單元測試、Worker 整合測試及語法檢查通過。依使用者要求未進行瀏覽器操作測試；iOS 白框與觸控實機效果待使用者驗收。

- 修正註冊／一般登入／復原登入在首頁留下 busy 畫面鎖定，成功與失敗均解除鎖定並恢復按鈕。

- 音樂與音效預設開啟、音量 100%。既有舊設定一次性遷移至新預設，之後自行調整的音量與開關照常保存。瀏覽器仍須第一次點擊／觸控才能開始音訊。

驗證：29 個單元測試通過，包含實際帳號提交函式的成功／失敗解除鎖定、音訊設定遷移、裝置辨識、小屋配樂路由及配件位置保存。Worker 整合測試另驗證配件移動與縮放後重新讀取。依使用者要求未進行瀏覽器操作驗收。

## 2026-10-18 功能心願與語音輸入

- 頂端新增「功能心願」，訪客及登入玩家都能寄送功能心願、使用建議或 Bug 回報。
- 信件寄到遊戲內管理員信箱，存在擁有者 Cloudflare D1；並非寄往外部電子郵件。
- 支援繁體中文語音轉文字、停止辨識、送出前修改；瀏覽器不支援或麥克風未允許時，提供鍵盤聽寫／打字替代方式。
- 聆聽時暫停背景音樂，關閉視窗／切到背景時停止麥克風；只保存信件文字，不儲存錄音。
- 本機保存未寄草稿；寄送失敗可重試，同封信的重試不會重複建立。
- 管理員登入後，功能心願內會出現「管理員心願信箱」，可分頁查看、標示未讀／已讀／已處理。一般玩家不能讀取或更改他人信件。
- 新增獨立 wishes 資料表與索引，保留既有帳號、進度及管理員設定。

驗證：31 個單元測試及帳號／遊戲／心願 API 整合測試通過，涵蓋重複寄送、輸入限制、寄送頻率、管理員權限、分頁與狀態保存。語音控制以模擬辨識事件驗證；實際瀏覽器與麥克風操作依使用者要求留待使用者驗收。
